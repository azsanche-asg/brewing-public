# Brewing

A native Mac workbench for everyday PDF, image, audio, video, file and text tasks.

[Brewing at Burrito’s Labs](https://brewing.burritoslabs.com/)

## Technology

Native macOS processing frameworks and direct, signed distribution for Apple silicon.

## Architecture

The app presents a catalogue of supported workflows. A task receives chosen files, exposes its options for review and creates a result separately from the original by default.

## Product behavior

Ordinary processing runs on the Mac. The official product site carries current requirements, trial and purchase information.
